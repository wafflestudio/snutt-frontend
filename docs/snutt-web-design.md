## 전체 레이아웃 구조

### 화면 구성 원칙
- 최소 너비: 1280px (데스크톱 전용)
- 세 가지 주요 레이어: 헤더 / 좌측 아이콘 바(또는 패널) / 시간표 그리드
- 패널 열릴 때 시간표가 우측으로 밀리는 구조 (push, 오버레이 아님)

---

## 헤더

```
[★ 시간표 1 (15학점)] [시간표 2] [시간표 3] [+]          [↓] [□□] [···]  [✎ 직접 추가] [↩ 기본]
```

| 요소 | 설명 |
|---|---|
| 시간표 탭 | 이름 + 학점 수. 현재 탭은 ★ 또는 강조 표시 |
| + 버튼 | 새 시간표 추가 |
| ↓ (내보내기) | 이미지 저장 |
| □□ (공유) | 링크/이미지 복사 공유 |
| ··· (더보기) | 드롭다운 메뉴 |
| ✎ 직접 추가 | 강의 직접 추가 폼 열기 (헤더에 상시 노출) |
| ↩ 기본 | 기본 시간표로 지정 |

## 좌측 아이콘 바 (Default State)

너비 약 60px. 아이콘만 표시, 텍스트 없음.

| 아이콘 | 기능 | 클릭 동작 |
|---|---|---|
| Q (검색) | 강의 검색 | 좌측 패널 열림 (검색 탭) |
| ♥ (관심강좌) | 관심강좌 | 좌측 패널 열림 (관심강좌 탭) |
| 👤 (친구) | 친구 | `/friends` 페이지 이동 |
| ··· (더보기) | 기타 메뉴 | |

## 레이아웃 States

### State 1 — Default (패널 없음)
```
[아이콘 바 60px] [시간표 그리드 전체 너비]
```

### State 2 — 패널 열림 (검색/관심강좌 클릭)
```
[아이콘 바 60px] [패널 ~320px] [시간표 그리드 나머지]
```
- 패널 상단: "검색 | 관심 목록 | 관심강좌" 3탭
- 탭 전환으로 콘텐츠 교체 (패널 크기 고정)

### State 3 — 강의 상세 (검색 결과 클릭)
```
[아이콘 바 60px] [검색 결과 목록] [강의 상세 중앙 패널] [시간표 그리드]
```
- 3-panel 레이아웃
- 강의 상세는 모달이 아닌 인라인 패널 (중요)

### State 4 — 직접 추가 폼
```
[아이콘 바 60px] [직접 추가 폼 패널] [시간표 그리드]
```
- 패널이 폼으로 전환
- 상단에 ← 뒤로가기, ✕ 닫기

### State 5 — 두 시간표 비교
```
[아이콘 바 60px] [시간표1 그리드] [시간표2 그리드]
```
- 시간표 2개 나란히 동시 표시
- 각 상단에 "시간표1", "시간표2" 헤더

---

## 시간표 그리드

| 속성 | 값 |
|---|---|
| 표시 요일 | 월, 화, 수, 목, 금, 토, 일 (7일) |
| 표시 시간 | 09:00 ~ 22:00 (또는 강의 시간 기반 자동 조절) |
| 강의 블록 | 색상 + 강의명 + 장소 표시 |
| Hover 미리보기 | 검색 결과 hover 시 해당 시간대 미리보기 표시 |

## 검색 패널

### 검색 탭
- 상단 검색창 (placeholder: "강의명, 교수명으로 검색")
- 필터 칩 (인검, 강종, 예약 등 빠른 필터)
- 검색 결과 리스트
  - 강의명
  - 교수명
  - 강의평 점수 (4.0/5.0 형식)
  - 시간/장소
  - + 담기 버튼

### 관심 목록 탭
- watchlist 형식 강의 목록 (관심강좌보다 상위 개념으로 추정)
- 항목별 삭제 가능

### 관심강좌 탭
- 북마크한 강의 목록
- 기존 snutt-webclient의 "관심강좌" 기능

## 필터 모달

중앙 다이얼로그 방식 (전체화면 아님).

### 레이아웃
```
[좌측 카테고리 목록] | [우측 필터 옵션]
```

### 카테고리 목록
| 카테고리 | 설명 |
|---|---|
| 선택기 | (선택한 필터 요약 표시) |
| 논문 | 논문 여부 필터 |
| 학과 | 학과 검색 + 인기학과 + 전체학과 (즐겨찾기 ★) |
| 외선 | 외국어 강의 여부 |
| 학위 | 학위 과정 필터 |
| 기간 | 수업 기간 |
| 교양영역 | 교양 서브 카테고리 |
| 교과과정력 | 교과과정 관련 필터 |
| **시간** | 시각적 시간표 연동 필터 (핵심 신규 기능) |
| 기타 | 없음 / 고유시 등 |

### 시간 필터 (특별)
- 시간 범위를 직접 시간표 그리드에서 블록 선택
- 선택한 시간대는 시간표에 음영으로 표시
- "이 시간대에 수업 없는 강의" 필터링

### 하단 액션
- 적용된 필터 태그 칩
- "필터 적용" (teal/primary 버튼)
- "초기화" 링크

## 친구 기능 디자인 (별도 페이지 `/friends`)

### 상단 탭
- ACTIVE (수락된 친구)
- REQUESTED (내가 받은 요청)
- REQUESTING (내가 보낸 요청)

### 친구 목록 아이템
```
[아바타] 닉네임 (커스텀 닉네임)    [시간표 보기] [···]
```

### 친구 시간표 뷰
- 읽기 전용 시간표 그리드
- 상단에 친구 이름 + 학기 선택
- 메인 시간표와 동일한 그리드 컴포넌트 (읽기 전용 props)

### 친구 추가 시트 (Bottom Sheet 또는 Dialog)
- 닉네임으로 추가
- Kakao 링크로 추가

## 소셜 로그인 페이지 (Figma 별도 페이지)
- 로고 + 서비스명
- 로컬 로그인 (ID/PW)
- 소셜 로그인 버튼: Google, Facebook, Kakao
- 회원가입 링크
- 비밀번호 찾기 링크

---

## 색상 시스템

### 시간표 강의 색상 (기존 유지)
- 여러 가지 파스텔 계열 색상 (8~10가지)
- 사용자가 강의별로 지정 가능
- 색상 피커 UI: 팔레트 형식

### 브랜드 컬러
- Primary (Teal): 버튼, 강조 요소
- 배경: 흰색 기반
- 텍스트: 다크 그레이 계열

## 디자인 정책 요약

| 항목 | 결정 |
|---|---|
| 네비게이션 형태 | 아이콘 바 (좁은 바) → 클릭 시 패널 (push) |
| 강의 상세 | 모달 아님, 인라인 중앙 패널 |
| 시간표 탭 | 헤더 수평 탭 (기존 드롭다운 → 탭으로 변경) |
| 시간 필터 | 시각적 시간표 블록 선택 |
| 비교 기능 | 두 시간표 나란히 (Split View) |
| 강의평 | 검색 결과 목록과 강의 상세에 점수 노출 |
| 반응형 | 데스크톱 우선 (최소 1280px) |
