## 먼저 답이 필요한 것

공용 컴포넌트(버튼, 입력칸, 탭 등)를 만들기 전에 필요한 내용입니다.

### A. 텍스트 스타일 — ✅ 대부분 해결 (2026-10-04)

`크기/굵기` 이름의 텍스트 스타일(`22/Bold` … `12/Medium`, 10개)이 생겨 개발에서도 같은 이름(`text-14-semibold`)으로 쓰고 있습니다.

**남은 요청**

1. 텍스트 스타일이 메인 화면(`home(1200 ~)`)과 `Web 컴포넌트` 에만 적용되어 있습니다. 강의 상세, 강의평, 강의 편집, 필터, 직접 추가, 팝업에도 적용해 주세요. 특히 아래 값은 지금 있는 스타일에 없습니다.

   | 요소                                   | 값                                   | 개발에서 임시로 쓰는 것 |
   | -------------------------------------- | ------------------------------------ | ----------------------- |
   | 버튼 글자 (직접 추가 · 팝업의 확인 등) | Pretendard 500 / 15px                | `15/Medium`             |
   | 강의 상세 · 직접 추가 제목             | Pretendard 700 / 20px / 줄 간격 140% | `20/Bold`               |
   | 직접 추가의 `시간 및 장소` 소제목      | Pretendard 600 / 16px / 줄 간격 140% | `16/SemiBold`           |
   | 강의 상세의 소제목 · 강의계획서 · 삭제 | Pretendard 600 / 15px / 줄 간격 140% | `15/SemiBold`           |

   강의 상세의 라벨 · 값은 14px Regular 이지만 줄 간격 140%, 자간 0 으로 `14/Regular`(120%, −2%)와 다릅니다. 개발은 `14/Regular` 를 씁니다.

2. 시간표 그리드의 강의 블록 글자(강의명 12px, 장소 12px Bold)는 **Noto Sans KR** 입니다. 다른 곳은 모두 Pretendard 인데, 블록만 다른 글꼴을 쓰는 것이 의도인지 알려 주세요.

### B. Variable 에 연결되지 않은 색

완료 영역에서 Variable 대신 hex 값이 직접 들어간 색이 약 45개 있습니다. 목록은 아래 [2장](#2-variable-에-연결되지-않은-색)에 요소별로 정리했습니다.

`Web 컴포넌트` 는 대부분 Variable 에 연결되어 있습니다. 남은 것은 `course`(그리드)의 `#F2F2F2` · `#EBEBED` · `#FFFFFF`, `cell` 의 `#FFFFFF` · `#000000` · `#E7E7E7` 입니다.

**요청**

1. 같은 값의 토큰이 이미 있는 색([2-1](#2-1-같은-값의-토큰이-있는-것))은 Variable 에 연결해 주세요.
2. 같은 값의 토큰이 없는 색([2-2](#2-2-같은-값의-토큰이-없는-것))은 토큰을 새로 만들지, 가까운 토큰으로 바꿀지 정해 주세요.
3. 같은 역할인데 색이 다른 곳([2-4](#2-4-같은-역할인데-색이-다른-것))은 하나로 맞춰도 되는지 알려 주세요.

**이유**

- 개발에서는 Figma Variables 를 그대로 가져와 색 이름(`Text/Normal` → `text-normal`)으로만 씁니다. hex 로 들어간 색은 이름이 없어서 어떤 토큰을 쓸지 개발자가 추측해야 합니다.
- 다크 모드는 Variables 의 Dark 값으로 바뀌는데, hex 로 들어간 색은 다크 모드에서도 바뀌지 않습니다.

### C. 아이콘

파일에 내보내기 제한이 걸려 있어 아이콘을 받을 수 없습니다.

**요청**: 아이콘 SVG 를 따로 받을 수 있을까요? 레이어 이름(`arrow_outward`, `wb_sunny`, `mobiledata_arrows`)으로 보아 Material Symbols 를 쓰신 것 같은데, 맞다면 같은 아이콘 세트를 쓰겠습니다. 직접 그리신 아이콘(SNUTT 로고, 시간표 탭 아이콘 등)만 따로 받으면 됩니다.

`Web 컴포넌트` 의 아이콘 이름(`dock_to_right`, `arrow_outward`, `bookmark`)도 Material Symbols 이름과 같아서, 개발은 Material Symbols 로 진행하고 있습니다. 좌측 바 아이콘(`Icon/Tab/timetable`), 검색 아이콘(`Icon/glass`), 필터 아이콘(`ic/condition/normal`)은 직접 그리신 것인지 알려 주세요.

## 3. Semantic 밖의 Variable

일부 요소가 `Semantic` 이 아닌 다른 컬렉션의 Variable 을 씁니다. Variables 내보내기에 포함되지 않아 값을 알 수 없습니다.

| Variable                      | 쓰인 곳                                                                          |
| ----------------------------- | -------------------------------------------------------------------------------- |
| `Fills/Secondary`             | 구분선 (강의 상세). 개발은 `Line/light`                                          |
| `Backgrounds/Secondary`       | 좌측 바 (메인)                                                                   |
| `Neutral/92`                  | 빈 별 (강의평)                                                                   |
| `GRAY10`, `GRAY2`, `White`    | 직접 추가 폼 (정확한 요소 미확인)                                                |
| `Grays/Gray`                  | 위치 미확인                                                                      |
| 이름이 `?` 로 보이는 Variable | 헤더 선택된 시간표 탭, 직접 추가 폼. 삭제된 Variable 을 참조하는 것으로 보입니다 |

**요청**: `Semantic` 토큰으로 바꿔 주시거나, 이 컬렉션들도 쓰는 것이라면 알려 주세요.

### 4-8. 직접 추가

[직접 추가](https://www.figma.com/design/LkgyyqYOaZXnbXcCGobavU/SNUTT_web-171016~-?node-id=3177-87728) · `시간 추가 클릭시` 프레임을 기준으로 만들면서 정해지지 않은 것입니다. 지금 개발한 동작은 [5장](#5-개발에서-임시로-정한-것)에 있습니다.

1. **`<` 와 `×`**: 폼 위의 두 버튼이 하는 일이 궁금합니다. 지금은 `<` 와 취소는 검색 목록으로 돌아가고, `×` 는 패널을 접습니다. 강의 상세 위의 `<` · `×` 도 같은 뜻으로 맞췄습니다(`<` 는 상세만 닫음).
2. **시간 선택 목록**: 시작 · 끝 시간을 몇 분 단위로, 몇 시부터 몇 시까지 고르게 할까요? Figma 에는 처음 값(월 오전 9:00 ~ 오전 10:00)만 있습니다. 수업이 :15, :45, :50 에 끝나는 경우가 많아 지금은 5분 단위, 오전 6:00 ~ 자정으로 했습니다.
3. **자정 표기**: 끝 시간 목록의 마지막인 자정(24:00)이 `오전 12:00` 으로 보입니다. 표기는 맞지만 목록 맨 위의 `오전 9:05` 보다 이른 시간처럼 읽힙니다. `밤 12:00` 으로 써도 될까요?
4. **고른 값의 글자색**: 드롭다운에 고른 값(`오전 9:00`, `색상1`)이 `#727272` 입니다. 같은 값의 토큰이 없고([2-2](#2-2-같은-값의-토큰이-없는-것)), 라벨도 같은 색이라 채운 값이 흐려 보입니다. 지금은 입력칸 글자와 같은 `Text/plain` 으로 했는데, 회색이 의도인지 알려 주세요.
5. **색상 견본 간격**: 색상 드롭다운의 `색상1` 과 견본 사이가 Figma 에서 더 넓습니다(약 18px, 개발 8px). 다른 곳의 색상 드롭다운(강의 상세, 펼친 목록)과 같은 간격으로 맞춰도 될까요?
6. **오류 표시**: 강의명이 비었을 때, 학점이 숫자가 아닐 때, 시간이 겹칠 때의 디자인이 없습니다. 지금은 칸 아래와 `시간 추가` 아래에 빨간 글자(`Text/warning`, 13px)를 띄웁니다.
7. **시간이 겹칠 때**: 시간표의 다른 강의와 겹치면 지금은 추가하지 않고 `‘경영전략’ 강의와 시간이 겹칩니다` 를 띄웁니다. 앱처럼 겹치는 강의를 빼고 넣을지 묻는 팝업을 띄워야 할까요?
8. ~~**첫 시간 줄의 `−`**~~ 반영 (10-17): 10-14 에 다시 그린 프레임에도 줄이 하나일 때 `−` 가 있어 Figma 대로 모든 줄을 지울 수 있게 바꿨습니다(강의 편집도 같음). 시간을 모두 지우면 시간 없는 강의가 되어 그리드에 보이지 않는데, 괜찮을까요?
9. **시간표가 없는 학기**: 시간표가 없는 학기에서 직접 추가를 열면 추가 버튼을 막고 `시간표를 먼저 만들어 주세요` 를 띄웁니다. 버튼을 아예 숨기는 것이 나을까요?

### 4-9. 강의 상세

[강의 상세](https://www.figma.com/design/LkgyyqYOaZXnbXcCGobavU/SNUTT_web-171016~-?node-id=3177-82418) 와 그 옆의 상세 패널 프레임(430 × 1221)을 기준으로 만들면서 정해지지 않은 것입니다.

1. **직접 추가한 강의의 상세**: 직접 추가한 강의는 수강편람 정보(학과, 강좌번호 등)가 없습니다. 지금은 `수강 정보` 와 `강의계획서` 를 빼고, 학점을 강의명 · 교수 아래에 둡니다. 이렇게 보여 줘도 될까요?
2. **정원(재학생)**: `정원(재학생)` 을 `80(60)` 처럼 정원 뒤 괄호에 재학생 정원(정원 − 신입생 정원)을 쓰는 것으로 이해했습니다. 맞나요?
3. **시간 표기**: 강의 상세는 `월 09:00 ~ 11:50`(24시간), 직접 추가는 `오전 9:00`(오전 · 오후)입니다. 같은 강의의 시간을 두 화면에서 다르게 쓰는데, 의도인지 알려 주세요.
4. **고른 강의 표시**: 시간표의 강의를 눌러 상세를 열었을 때 그리드에서 그 강의를 따로 표시하나요? Figma 에는 표시가 없어 지금은 그대로 둡니다.
5. **삭제 글자색**: `삭제` 가 `#E54459`(`SNUTT/red`, 강의 블록 빨강)입니다. 경고 색 `Text/warning`(`#ED6C58`)이 따로 있는데, 어느 것을 써야 할까요? 지금은 Figma 대로 `SNUTT/red` 입니다.
6. **삭제 확인**: 삭제를 누르면 묻는 팝업 디자인이 없어서 확인 팝업 모양으로 `‘경영전략’ 강의를 삭제하시겠습니까?` 를 띄웁니다.

### 4-10. 서버와 연결한 메인 화면

메인 화면을 실제 서버 데이터에 연결하면서 생긴 상태입니다. Figma 에 디자인이 없어 지금은 아래처럼 둡니다.

1. **불러오는 중**: 처음 시간표를 받는 동안 시간표 자리 가운데에 `불러오는 중` 글자만 띄웁니다. 스켈레톤이나 스피너 디자인이 있을까요?
2. **불러오지 못했을 때**: 시간표 자리 가운데에 `시간표를 불러오지 못했습니다` 와 서버 메시지를 띄웁니다. 다시 시도 버튼이 필요할까요?
3. **요청이 실패했을 때**: 시간표 추가 · 강의 삭제 같은 동작이 실패하면 서버가 준 메시지(예: `존재하지 않는 시간표입니다`)를 확인 버튼 하나짜리 팝업으로 띄웁니다. 확인 팝업(`팝업 예시`)에서 취소를 뺀 모양입니다. 토스트처럼 잠깐 떴다 사라지는 쪽이 나을까요?

### 4-11. 검색 결과

[Web 컴포넌트](https://www.figma.com/design/LkgyyqYOaZXnbXcCGobavU/SNUTT_web-171016~-?node-id=3214-8621) 의 `cell` · `검색 목록 영역` 을 기준으로 만들면서 정해지지 않은 것입니다.

1. **검색어가 없을 때**: 서버가 검색어 없이도 학기의 모든 강의를 주어서, 검색 탭을 열면 바로 전체 강의를 보여 줍니다. 검색어를 쳐야 결과를 보여 주는 쪽이 맞을까요?
2. ~~**회색 배경 `cell`**~~ ✅ 해소 (10-13): 두 번째 변형의 이름이 `호버` 로 정해져 커서를 올렸을 때로 쓴 것이 맞습니다.
3. **결과를 눌렀을 때**: 검색 결과를 눌렀을 때의 동작과 담지 않은 강의의 상세 화면이 Figma 에 없습니다. 지금은 셀(버튼 · 강의계획서 밖)을 누르면 목록 옆에 강의 상세를 엽니다(10-17). 담긴 강의는 시간표 강의의 상세와 같고, 담지 않은 강의는 같은 배치에서 색상 · 강의편집 · 삭제 대신 `시간표에 담기` 를 둡니다. 담으면 시간표 강의의 상세로 바뀝니다. 담지 않은 강의의 상세 화면을 따로 그려 주실 수 있을까요? 관심강좌 버튼도 상세에 있어야 할까요?
4. **강의평 바로가기**: `강의평 바로가기 버튼`(`★ 4.0 (1)`, 밑줄)은 강의평 화면(8-4)이 생기면 연결하고, 지금은 글자로만 보여 줍니다.
5. **시간이 겹칠 때**: 서버가 주는 문구(`'경영전략' 강의와 시간이 겹칩니다. 강의를 덮어씌우겠습니까?`)를 확인 팝업에 그대로 띄우고, 확인하면 겹치는 강의를 빼고 넣습니다. 따로 정한 문구가 있을까요?
6. **불러오는 중 · 결과 없음**: 목록 자리에 `불러오는 중`, `검색 결과가 없습니다` 글자만 띄웁니다. 30개씩 받고 목록 끝에 닿으면 다음 30개를 받습니다.

### 4-12. 로그인 · 회원가입

완료 영역에 웹 로그인 화면이 없어, 예전 웹 디자인(`소셜로그인(구)` 페이지의 `05_login (1170~px)`) 구성을 지금 토큰과 공용 컴포넌트로 만들었습니다.

1. **화면**: 가운데에 로고 · `시작하기`, 아이디 · 비밀번호 입력칸, 로그인 버튼, 아래에 `회원가입` 링크. 새 디자인이 있을까요?
2. **로그인 유지**: 예전 디자인의 `로그인 유지` 체크박스는 뺐습니다. 지금은 로그아웃하기 전까지 늘 로그인이 유지됩니다.
3. **소셜 로그인 · 비밀번호 찾기**: 각각 3-2 · 3-3 에서 붙입니다.
4. **회원가입**: 아이디, 비밀번호, 비밀번호 확인, 이메일(선택). 비밀번호 규칙(`영문과 숫자를 모두 포함한 6~20자`)은 서버 규칙을 그대로 안내합니다. 닉네임은 서버가 정합니다.

### 4-13. 검색 결과 미리보기

검색 결과에 커서를 올리면 시간표에 그 강의가 들어갈 자리를 보여 줍니다. 지금 완료 영역에는 이 상태의 프레임이 없어 아래처럼 만들었습니다.

1. ~~**색**~~ ✅ 해소 (10-13): 완료 영역 `관심강좌` 프레임에 같은 미리보기가 생겨 `Background/deem` 블록에 흰 글자로 맞췄습니다.
2. **그리드 밖의 시간**: 토요일이나 22시 이후처럼 지금 그리드에 없는 시간은 그리드를 늘리지 않고 보이는 만큼만 그립니다. 커서를 옮길 때마다 그리드 크기가 바뀌면 어지러워서입니다.
3. **비교 중**: 검색 결과는 왼쪽 시간표에 담기므로 미리보기도 왼쪽에만 보여 줍니다.
4. **이미 담긴 강의**: 담긴 강의에 커서를 올려도 같은 자리에 겹쳐 보여 줍니다.

### 4-14. 강의 편집

예전 `강의 편집` 링크의 프레임은 지워졌고, 완료 영역 `강의상세` 프레임 하나에 강의명만 입력칸(높이 28, 둥글기 5, `Background/light`)으로 바뀐 상태가 있습니다. 나머지는 아래처럼 만들었습니다.

1. **고칠 수 있는 것**: 강의명 · 교수 · 색상 · 비고 · 시간 및 장소. 직접 추가한 강의는 학점도 고칩니다. 수강 정보(학과, 강좌번호 등)는 수강편람 값이라 고치지 않고 그대로 보여 줍니다. 수강편람 강의의 학점도 고칠 수 있어야 할까요?
2. **입력칸 모양**: 강의명 입력칸 모양을 교수 · 학점 · 비고 · 장소에도 썼습니다. 요일 · 시간 선택칸은 직접 추가와 같은 테두리 있는 칸입니다.
3. **시간 및 장소**: 직접 추가와 같은 줄(요일 · 시작 · 끝, 장소, `−`, `시간 추가`)입니다. 라벨 `시간` · `장소` 를 위쪽 줄들처럼 80px 로 두면 시간 선택칸이 좁아 `오후 12:00` 이 잘려서 직접 추가처럼 40px 로 두었습니다.
4. **저장 · 취소**: 맨 아래 강의계획서 · 강의편집 · 삭제 자리에 직접 추가와 같은 `취소` · `저장` 버튼을 둡니다. 바뀐 것이 없이 저장하면 그냥 닫습니다.
5. **시간이 겹칠 때**: 검색에서 담을 때처럼 서버 문구(`'…' 강의와 시간이 겹칩니다. 강의를 덮어씌우겠습니까?`)로 묻고, 확인하면 겹치는 강의를 빼고 저장합니다. 입력한 시간끼리 겹치면 저장하지 않습니다.
6. **원래대로**: 수강편람 강의를 고친 뒤 수강편람 값으로 되돌리는 버튼(앱의 `초기화`)은 아직 없습니다. 웹에도 필요할까요?

### 4-15. 10-12 ~ 10-14 수정분

완료 영역을 다시 그린 10-12 ~ 10-14 수정분을 반영하면서 생긴 질문입니다.

1. **강의 상세 / 강의평 전환 순서**: `강의상세` 프레임은 `강의 상세 | 강의평`, `강의평` 프레임은 `강의평 | 강의 상세` 순서입니다. 고른 쪽을 앞에 두는 뜻일까요? 지금은 늘 `강의 상세 | 강의평` 순서입니다.
2. **좁은 헤더**: 강의 상세가 열린 프레임은 헤더의 `직접 추가` · `시간표 비교` 가 아이콘만 남아 있어 상세가 열렸을 때 아이콘만 보여 주게 했습니다. 상세를 닫으면 다시 글자가 보입니다.
3. **시간대 검색**: 필터의 `시간` 을 누르면 열리는 `시간대 검색` 모달이 완료 영역에 들어와 5-4 에서 개발했습니다. 질문은 [4-18](#4-18-시간대-검색)에 있습니다.

### 4-16. 친구 목록

Figma 에 친구 화면이 아직 없어(완료 · 작업 중 영역 모두, 10-17 확인) 디자인 스펙의 세 탭으로 `/friends` 를 만들었습니다.

1. **화면 구성**: 메인 화면의 목록 패널과 같은 430px 패널에 제목 `친구`, 밑줄 탭 `친구` · `받은 요청` · `보낸 요청`, 그 아래 목록을 둡니다. 오른쪽 넓은 자리는 친구 시간표(8-3)를 보여 줄 곳으로 비워 두었습니다. 친구 화면도 이런 구성이 맞을까요?
2. **목록 한 줄**: 위에 이름(`15/Bold`, 내가 붙인 이름이 있으면 그 이름, 없으면 닉네임), 아래에 `닉네임#0562`(`13/Regular`, `Text/Assistive`)를 씁니다. 서버에 프로필 사진이 없어 디자인 스펙의 아바타는 뺐습니다. 아바타 자리에 기본 그림을 둘까요?
3. **받은 요청**: 줄 오른쪽에 `거절`(회색) · `수락`(민트) 버튼(헤더의 작은 버튼 크기)을 둡니다. 거절은 묻지 않고 바로 처리합니다. 거절 전에 확인 팝업이 필요할까요?
4. **보낸 요청**: 지금은 목록만 보여 줍니다. 보낸 요청을 취소하는 버튼이 필요할까요? (서버에는 친구 삭제와 같은 요청으로 취소할 수 있습니다)
5. **받은 요청 알림**: 받은 요청이 있어도 탭을 열기 전에는 알 수 없습니다. 탭 이름 옆이나 좌측 바 `친구 시간표` 에 개수 · 점 표시가 필요할까요?
6. **빈 목록 · 불러오는 중**: 목록 자리에 `아직 친구가 없습니다` · `받은 친구 요청이 없습니다` · `보낸 친구 요청이 없습니다`, `불러오는 중` 글자만 띄웁니다. 친구 추가(8-2)로 이끄는 안내가 필요할까요?

### 4-17. 관심강좌 탭

완료 영역 `관심강좌` 프레임을 기준으로 만들면서 정해지지 않은 것입니다.

1. **검색창 · 필터 칩**: 프레임에 검색 탭과 같은 검색창과 필터 칩이 있습니다. 관심강좌 안에서 찾는 것인지, 검색 프레임을 복사하다 남은 것인지 궁금합니다. 지금은 두지 않고 목록만 보여 줍니다.
2. **이동 확인 팝업**: 검색 탭에서 관심강좌를 켤 때마다 `관심강좌 탭으로 이동하시겠습니까?` 를 묻습니다. 끌 때는 묻지 않습니다. 매번 묻는 것이 맞을까요?
3. **관심강좌를 끌 때**: 관심강좌 탭에서 끄면 바로 목록에서 빠집니다. 되돌리기나 확인이 필요할까요?
4. **빈 목록**: `관심강좌가 없습니다` 글자만 띄웁니다.

### 4-18. 시간대 검색

완료 영역 `home` 섹션의 `필터 기타` 옆 `home(1200 ~)` 프레임(`시간대 검색` 모달, 695 × 838)을 기준으로 만들면서 정해지지 않은 것입니다.

1. **고른 시간과 `빈 시간대만 검색`**: `필터 시간` 프레임은 `빈시간대만 검색하기` / `시간대 직접 선택하기` 중 하나를 고르는 라디오인데, `시간대 검색` 모달은 그리드에서 시간을 고른 채로 아래 `빈 시간대만 검색` 을 따로 켜는 모양입니다. 서버는 두 조건을 함께 받아 둘 다 만족하는 강의(고른 시간 안에 있으면서 시간표 강의와 겹치지 않는 강의)를 주므로, 지금은 함께 고를 수 있게 했습니다. 의도와 같은지, `필터 시간` 의 라디오는 이 모달로 바뀐 것인지 알려 주세요.
2. **들어오는 곳**: 필터 모달(5-3)이 아직 없어서, 지금은 검색창 오른쪽의 필터 아이콘을 누르면 이 모달이 바로 열립니다. 필터 모달이 생기면 왼쪽 목록의 `시간` 에서 열도록 바꿉니다. 적용한 조건은 검색창 아래 민트 칩(`시간대 검색 ×`, `빈 시간대만 ×`)으로 보여 주는데, 칩 이름 · 색을 정해 주세요. ([4-4](#4-화면))
3. **회색 블록**: 그리드의 회색 블록(`#787880 · 20%`)을 고른 시간표에 담긴 강의의 시간으로 이해했습니다. 지금은 가까운 `Line/border`(`#E4E4E5`)로 그리고, 고른 칸(민트 50%)이 겹치면 진하게 보입니다.
4. **고를 수 있는 시간**: Figma 는 월~금, 9시 ~ 21시입니다. 지금은 메인 시간표와 같이 월~금 9시 ~ 22시이고, 시간표에 토요일이나 범위 밖 강의가 있으면 그만큼 넓힙니다. 30분 단위로 고릅니다. 주말 · 이른 아침 · 늦은 밤도 늘 고를 수 있어야 할까요?
5. **안내 상자**: `검색하고 싶은 시간을 드래그하세요.` 는 모달을 열 때마다 보여 주고 `확인` 을 누르면 그 모달에서만 사라집니다. 한 번 확인하면 다시 보이지 않게 할까요? 배경 `#000000 · 50%` 는 토큰이 없어 임시 색으로 넣었습니다.
6. **닫기 · 초기화**: `×` · Esc · 바깥을 누르면 고친 것을 버리고, `완료` 를 눌러야 검색에 씁니다. `초기화` 는 모달 안의 고른 칸과 `빈 시간대만 검색` 을 지우고, 완료를 눌러야 검색 조건도 지워집니다.
7. **글자 · 색**: 제목 `20px SemiBold` 는 텍스트 스타일이 없어 `20/SemiBold` 를 임시로 만들었습니다. `빈 시간대만 검색` · `초기화` 의 `#666666` 은 `Text/Plain`(`#505050`), 체크박스 테두리 `#C7C7CC` 는 `Line/divider`(`#C4C4C4`) 로 대신했습니다. `완료` 버튼(80 × 32, 둥글기 5)은 다른 팝업 버튼과 같은 높이 38 로 두었습니다.
8. **서버가 빼는 강의**: 시간 조건을 걸면 서버가 수업 시간이 없는 강의(원격 · 시간 미정 등)를 결과에서 뺍니다. `빈 시간대만 검색` 에서도 빠지는데, 괜찮을까요?

### 4-19. 강의평 보기

완료 영역 `home` 섹션의 [강의평 상세](https://www.figma.com/design/LkgyyqYOaZXnbXcCGobavU/SNUTT_web-171016~-?node-id=3406-36178) 프레임을 기준으로 강의 상세의 `강의평` 쪽을 만들면서 정해지지 않은 것입니다. 강의평 작성 · 좋아요 · ⋮ 메뉴는 다음 단위(8-5)에서 만듭니다.

1. **태그 탭 통계**: `성적 · 과제 · 수강신청 · 팀플` 탭과 `한 만큼 나와요 90%` 같은 막대를 주는 API 가 없습니다(v2 명세에 없음, 백엔드 문의 중). 가짜 값을 보여 줄 수 없어 지금은 탭 자체를 뺐습니다. 서버가 생기기 전까지 빼 두어도 될까요?
2. **이메일 인증**: 강의평은 이메일 인증을 한 사용자만 볼 수 있습니다(서버가 403). 지금은 강의평 자리에 서버 문구 `이메일 인증이 완료된 후 강의평을 확인할 수 있습니다` 만 띄웁니다. 인증 화면 · 인증하러 가는 버튼 디자인이 필요합니다.
3. **직접 추가한 강의**: 수강편람 강의가 아니라 강의평이 없습니다. `직접 추가한 강의는 강의평이 없습니다` 글자만 띄웁니다. `강의평` 전환 버튼을 숨기거나 누를 수 없게 할까요?
4. **강의평이 없을 때 · 불러오는 중**: 평균 점수와 항목별 점수 자리에 `-`, 별은 모두 회색, 목록 자리에 `아직 강의평이 없습니다` 를 띄웁니다. 불러오는 중은 `불러오는 중` 글자만 띄웁니다.
5. **전환 버튼 순서**: `강의평 상세` 프레임은 `강의평 | 강의 상세`, `강의 상세` 프레임은 `강의 상세 | 강의평` 순서입니다. 지금은 두 화면 모두 `강의 상세 | 강의평` 으로 두었습니다.
6. **본문 더보기**: 본문은 두 줄까지 보여 주고, 넘치면 아래에 `더보기` 를 두어 누르면 펼칩니다. Figma 처럼 둘째 줄 끝 `...더보기` 로 붙이려면 글자 수를 재야 해서 줄 아래에 두었습니다. 접는 버튼은 없습니다.
7. **정렬 · 쪽 넘김**: 처음에는 Figma 대로 `추천순` 입니다(서버 기본값은 최신순). 패널을 끝까지 내리면 다음 강의평을 이어 받습니다.
8. **글자 · 색**: 평균 점수 `36px Medium #000000` 은 `Text/Normal` 로, 교수 / 학점 `#505050` 은 `Text/Plain` 으로 바꿨습니다. 텍스트 스타일이 없는 평균 점수(36/Medium) · 항목별 점수(13/SemiBold)는 임시 스타일을 만들었고, 학기 · 본문은 `13/body/regular` 를 씁니다. 빈 별(`Neutral/92`)은 Semantic 에 없어 `Line/light` 를 씁니다.

### 4-20. 시간표 내보내기 (공유 · 다운로드)

디자인 변경 표의 헤더 `공유 · 다운로드`(9-1)를 만들면서 정해지지 않은 것입니다. 지금 `Web 컴포넌트` 의 `top` 에는 두 아이콘이 없습니다([4-7](#4-화면)).

1. **자리 · 아이콘**: 예전 시안처럼 `···` 왼쪽에 아이콘 버튼 두 개(공유 · 다운로드)를 두었습니다. 아이콘은 Material Symbols `share` · `download`, 색은 다른 헤더 아이콘과 같은 `Text/med` 입니다. 비교 중에는 `top` 의 `메인 시간표` 변형처럼 `···` 만 남기고 숨겼습니다. 헤더에 두는 것이 맞는지, `···` 메뉴로 옮기는 것인지 알려 주세요.
2. **공유가 하는 일**: 서버에 시간표 공유 링크 API 가 없어 링크가 아니라 **이미지**를 공유합니다. 브라우저가 파일 공유를 지원하면 운영체제의 공유 창을 열고, 아니면 이미지를 클립보드에 복사한 뒤 `시간표 이미지를 복사했습니다` 알림 팝업을 띄웁니다. 예전 웹(snutt-webclient)에는 공유 · 다운로드가 없었습니다. 의도한 공유가 링크(받는 사람이 웹에서 보는 시간표)라면 백엔드 작업이 필요합니다.
3. **이미지에 들어가는 것**: 화면의 시간표 그리드(요일 · 시각 · 강의 블록)를 화면에 보이는 크기 그대로 2배 해상도로 만듭니다. 시간표 이름 · 학점 · 로고는 넣지 않았고, 파일 이름이 `<시간표 이름>.png` 입니다. 다크 테마면 이미지도 어둡게 나옵니다. 이미지용 디자인(고정 크기, 제목, 워터마크, 테마)이 따로 있을까요?
4. **알림**: 복사 완료 · 실패를 확인 버튼 하나짜리 알림 팝업으로 알립니다. 잠깐 떴다 사라지는 알림(토스트) 디자인이 있으면 바꾸겠습니다.
