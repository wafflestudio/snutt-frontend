## 1. Variables 값

## 2. Variable 에 연결되지 않은 색

완료 영역 전체에서 Variable 대신 hex 가 직접 들어간 색이 약 45개다.
개발에서는 모든 색을 토큰으로 쓰므로, 아래 요소들을 Variable 에 연결하거나 어떤 토큰을 쓸지 정해 주면 좋겠다.

### 2-3. 위치를 확인하지 못한 것

완료 영역의 선택 색상 목록에는 있지만 어느 요소인지 찾지 못했다. 강의평, 강의 편집(색상 드롭다운), 직접 추가, 지도 프레임에 있을 것으로 보인다.

`#E7E7E7`, `#121212`, `#E6E6EB`, `#F2F4F6`, `#727272`, `#E9E9EA`, `#A6A6A6`, `#F7F7F7`, `#E6EAEC`, `#F58D3D`, `#2BC267`, `#4F48C4`, `#000000 · 40%`, `#787880 · 16%`, `#DADADA · 50%`

### 2-4. 같은 역할인데 색이 다른 것

| 역할           | 쓰인 색                                                                                                    |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| 비선택 탭 글자 | 패널 탭(강의 목록) `Text/med` · 헤더 시간표 탭 `#B8B8B8` · 상세 전환 `#B8B8B8`                             |
| 회색 아이콘    | 검색 결과 관심강좌 / 담기 `Text/med` · 헤더 아이콘 `#979797` · 상세 닫기 `#B8B8B8` · 검색창 필터 `#DADADA` |
| 옅은 배경      | 검색창 `#F3F4F5` · 좌측 바 `#F6F7F9` · 필터 카테고리 선택 `#F2F2F2` · `Background/light` `#F7F7F7`         |

하나로 맞춰도 되는지 확인이 필요하다.

## 3. Semantic 밖의 Variable

일부 요소가 `Semantic` 컬렉션이 아닌 Variable 을 쓴다. Variables 내보내기에 포함되지 않아 값을 알 수 없다.

| Variable                            | 쓰인 곳                      |
| ----------------------------------- | ---------------------------- |
| `Fills/Secondary`                   | 강의 상세 구분선             |
| `Backgrounds/Secondary`             | 좌측 바                      |
| `White`, `Neutral/92`, `Grays/Gray` | 완료 영역 곳곳 (위치 미확인) |

`Semantic` 의 토큰(`Line/divider` 등)으로 바꿔도 되는지, 아니면 이 컬렉션도 받을 수 있는지.
