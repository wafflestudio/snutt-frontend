## 먼저 답이 필요한 것

공용 컴포넌트(버튼, 입력칸, 탭 등)를 만들기 전에 필요한 내용입니다.

### A. 텍스트 스타일

Variables 에 색은 있지만 글자 크기 · 굵기 · 줄 간격 단계는 없습니다. 지금은 요소마다 값이 다릅니다.

| 요소             | 값                                              |
| ---------------- | ----------------------------------------------- |
| 강의 상세 제목   | Pretendard 700 / 20px / 줄 간격 140%            |
| 검색창 안내 문구 | Pretendard 400 / 14px / 줄 간격 100%            |
| 좌측 바 라벨     | Pretendard 600 / 13px / 줄 간격 150% / 자간 -3% |

**요청**: 텍스트 스타일(예: 제목 / 본문 / 캡션 단계)이 정해져 있다면 알려 주세요. 없다면 위처럼 쓰인 값을 몇 단계로 묶어 정해 주시면 좋겠습니다.

**이유**: 개발에서는 크기를 단계 이름(`title`, `body` …)으로만 씁니다. 단계가 없으면 화면마다 숫자를 따로 넣게 되고, 나중에 크기를 바꿀 때 전부 찾아 고쳐야 합니다.

### B. Variable 에 연결되지 않은 색

완료 영역에서 Variable 대신 hex 값이 직접 들어간 색이 약 45개 있습니다. 목록은 아래 [2장](#2-variable-에-연결되지-않은-색)에 요소별로 정리했습니다.

**요청**

1. 같은 값의 토큰이 이미 있는 색([2-1](#2-1-같은-값의-토큰이-있는-것))은 Variable 에 연결해 주세요.
2. 같은 값의 토큰이 없는 색([2-2](#2-2-같은-값의-토큰이-없는-것))은 토큰을 새로 만들지, 가까운 토큰으로 바꿀지 정해 주세요.
3. 같은 역할인데 색이 다른 곳([2-4](#2-4-같은-역할인데-색이-다른-것))은 하나로 맞춰도 되는지 알려 주세요.

**이유**

- 개발에서는 Figma Variables 를 그대로 가져와 색 이름(`Text/Normal` → `text-normal`)으로만 씁니다. hex 로 들어간 색은 이름이 없어서 어떤 토큰을 쓸지 개발자가 추측해야 합니다.
- 다크 모드는 Variables 의 Dark 값으로 바뀌는데, hex 로 들어간 색은 다크 모드에서도 바뀌지 않습니다.

### C. 아이콘

파일에 내보내기 제한이 걸려 있어 아이콘을 받을 수 없습니다.

**요청**: 아이콘 SVG 를 따로 받을 수 있을까요? 레이어 이름(`arrow_outward`, `wb_sunny`, `mobiledata_arrows`)으로 보아 Material Symbols 를 쓰신 것 같은데, 맞다면 같은 아이콘 세트를 쓰겠습니다. 직접 그리신 아이콘(SNUTT 로고, 시간표 탭 아이콘 등)만 따로 받으면 됩니다.

지금은 Figma 값을 그대로 넣었습니다. 답을 받으면 Variables 를 다시 내보내 반영합니다.

| #   | 내용                                                                                                             | 확인할 점                                                     |
| --- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| 1-1 | 다크 모드에서 `SNUTT/green` 과 `SNUTT/lime` 이 둘 다 `#95B03E` 입니다                                            | green 의 다크 값이 잘못 들어간 것인지                         |
| 1-2 | 다크 모드 `Line/cellBorder` 가 라이트와 같은 `#000000 · 10%` 입니다                                              | 다크 배경(`#222222`)에서는 거의 보이지 않는데 의도하신 값인지 |

## 3. Semantic 밖의 Variable

일부 요소가 `Semantic` 이 아닌 다른 컬렉션의 Variable 을 씁니다. Variables 내보내기에 포함되지 않아 값을 알 수 없습니다.

| Variable                | 쓰인 곳            |
| ----------------------- | ------------------ |
| `Fills/Secondary`       | 구분선 (강의 상세) |
| `Backgrounds/Secondary` | 좌측 바 (메인)     |
| `Neutral/92`            | 빈 별 (강의평)     |
| `White`, `Grays/Gray`   | 위치 미확인        |

**요청**: `Semantic` 토큰으로 바꿔 주시거나, 이 컬렉션들도 쓰는 것이라면 알려 주세요.
